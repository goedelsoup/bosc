# Ohio Water Quality Standards (OAC 3745-1) — numeric criteria

The per-chemical Ohio water-quality criteria the **industrial toxic screen**
(`watermark.hydrology.toxics`) compares each pollutant's derived receiving-water concentration
against — the chemical-specific replacement for the old flat `1.0 mg/L` aggregate band
(epic #1600, finding **WS-07** / #1607). Read by `watermark.hydrology.criteria`; regenerable —
every value is transcribed from the cited Ohio Administrative Code rule/table, nothing is
fabricated.

## Files

| File | What | Source |
|---|---|---|
| `ohio-water-quality-criteria.yaml` | Per-chemical acute (CMC/OMZM), chronic (CCC/OMZA), and human-health (public water supply) criteria in mg/L, keyed by the RSEI chemical token (CAS or `Nxxx` category code). Hardness-dependent metals carry their Table 35-9 equation. | OAC **3745-1-35** (aquatic life, Tables 35-1/35-2/35-5/35-9) and **3745-1-33** (human health, Table 33-1). `source: reference`. |

## Discipline

- **Screening, not a wasteload allocation.** The toxic screen carries each facility's reported
  water pounds at a receiving-stream design flow, fully mixed, no decay or mixing-zone credit.
  A derived concentration below a criterion is reassuring; a value above it flags the need for a
  permit-level assimilative-capacity (WQBEL) determination, **not** an automatic violation.
- **`reference`, never `verified`.** These are published state standards — a prior the derived
  concentration is held against, not a fact about the receiving water. Surfaced as
  `ProvenancedValue` they are tagged `reference`.
- **Criterion type pairs to design flow** (`watermark.hydrology.toxics` wires this, WS-07/WS-08):
  acute (CMC / OMZM) → **1Q10**, chronic (CCC / OMZA) → **7Q10**, human health → **harmonic mean**.
  Ohio expresses acute as "maximum outside the mixing zone" (OMZM) and chronic as "outside mixing
  zone 30-day average" (OMZA); this screen assumes complete mix (no mixing-zone credit).
- **Omit, don't guess.** A chemical with no numeric Ohio criterion (ethylene glycol, methanol,
  acetonitrile, diethanolamine, MTBE, …) is left out; the screen reports it as "no criterion"
  rather than inventing one.
- **Two stated screening assumptions** (in the file's `assumptions:` block, re-derivable):
  - **Hardness = 100 mg/L CaCO₃.** Metals criteria (Table 35-9) are hardness-dependent; no Ottawa
    River hardness is cited in the corpus, so criteria are evaluated at EPA/Ohio's standard
    reference hardness. Each metal carries its equation so the criterion re-derives at a cited
    hardness.
  - **Ammonia at pH 8.0 / 25 °C, March–November.** The ammonia criterion (Tables 35-2/35-5) is a
    pH × temperature surface; it is screened at a stated summer growing-season design condition —
    the May–Oct precipitation-deficit window the report frames, when the Ottawa mainstem's
    assimilative capacity is lowest.
  - **Chromium screened as Cr(VI).** RSEI's chromium category lumps trivalent and hexavalent; the
    screen uses the more-protective Cr(VI) criterion conservatively.
  - **Nitrate expressed as NO₃ (44 mg/L).** RSEI reports the nitrate-ion mass; the 10 mg/L-as-N
    public-water-supply MCL is expressed as 44 mg/L NO₃ (×62/14) so load and criterion share a
    basis (conservative if the reported mass were already as N).
- **Cross-checked.** The Table 35-9 hardness-metal equations reproduce EPA's National Recommended
  Criteria at 100 mg/L hardness (nickel 468 vs 470, zinc 117 vs 120, copper 13 vs 13 µg/L).
- **Keep it current.** Re-transcribe from the cited OAC rule if Ohio revises a criterion.
