# Public-records legislation (original records)

**Collection:** `legal/records-legislation/` · immutable source evidence

Verbatim bill text for legislation that would amend the statute this corpus's
public-records work rests on — **R.C. 149.43**, the Ohio Public Records Act. Raw
bytes are never edited; the reviewed reads and analysis live in the mirrored
[`data/extracted/legal/records-legislation/`](../../../extracted/legal/records-legislation/).

## Contents

| File | What |
|---|---|
| `hb314_00_IN.pdf` | **H.B. No. 314, 136th G.A. — As Introduced** (42 pp; no cosponsors). The original text before the committee substitute. |
| `hb314_02_PH.pdf` | **Sub. H.B. No. 314, 136th G.A. — As Passed by the House** (48 pp). Amends R.C. 149.43 to (1) let a public office sue a requester to limit/deny "harassing or disruptive" requests and (2) let an office engage a private contractor to answer "voluminous" requests and bill the requester for it. Sponsors: Reps. Isaacsohn, Ray. |
| `filename-map.yaml` | Canonical-name + provenance map for both versions (as-received LSC filename → canonical name, sha256, content-verified date). |

The as-received names are Ohio LSC document codes (`hb314_00_IN` = HB 314, doc 00,
"IN" = As Introduced; `hb314_02_PH` = doc 02, "PH" = As Passed by the House). Keep
them; canonical names are in `filename-map.yaml`. Both are pre-enactment House
versions — Senate/enacted versions are separate [open] ingest targets. The
strike/underline amendatory markup is lost in the text layer, so cite page/line
numbers against the PDF. The introduced→passed diff is analyzed in the
[extracted reads](../../../extracted/legal/records-legislation/README.md).
