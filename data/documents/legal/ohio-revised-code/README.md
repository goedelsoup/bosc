# `legal/ohio-revised-code/` — authenticated statute text

Statutes this corpus reasons against, pulled as the **Legislative Service Commission's authenticated
PDF** rather than quoted from a code-publisher website or a party's paraphrase.

This directory is deliberately **not** under a site. A statute is not any watershed point's record;
several sites reason against the same section, and filing it under one would attribute it to that
site's corpus scope.

| File | Why |
|---|---|
| `122.17-10-3-2023.pdf` | R.C. 122.17 — the megaproject / megaproject-operator definitions on which Sidney's thirty-year abatement rests, the four-prong test, the wage floor, the threshold indexation, and the reporting duties at (D)(11)–(D)(12) |

**Version discipline.** The filename carries the effective date because the authenticated series is
versioned. The 2023-10-03 text is both the version in force at every Sidney event and the latest
version; the published version history lists no amendment after it. That forecloses any objection
that a party was reading a different text.

Custody, SHA-256 and source URLs: [`filename-map.yaml`](filename-map.yaml).
